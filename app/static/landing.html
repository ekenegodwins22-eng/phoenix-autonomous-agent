Autonomous browsing

Phoenix drives a real browser: it reads pages, clicks, fills forms, and reports back with screenshots of what it saw.

Background tasks

Start a task and close the tab. It keeps running on the server, and you check progress, logs, and files whenever you come back.

Checkpoint resume

Progress is saved as it goes. If a run crashes, a restart or a session limit hits, Phoenix resumes from the last checkpoint instead of starting over.
